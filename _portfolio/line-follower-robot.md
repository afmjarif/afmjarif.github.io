## About the Project
An autonomous line follower robot built on Arduino Nano, used in the Line Follower Robotics Contest and Robotics Fest.

### 🛠️ Tech Stack
*   **Hardware:** Arduino Nano, IR sensors, motor driver, DC motors
*   **Software:** C/C++, Arduino IDE
